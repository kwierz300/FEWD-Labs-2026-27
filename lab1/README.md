# Lab 1 – JavaScript for React

Practice implementation based on the GCU FEWD Lab 1 instructions and starter code by Fiona MacRae Fairlie, with AI assistance.

## Running
- Open the HTML files in part1-clientsidejs using Live Server. Open the console for objects.html.
- Run the ES6, async and module exercises using Node.js.
- In part3-typescript run npm install, npm run build, then npm start.

## Manual checks
Set a Chrome DevTools breakpoint in showPerson, inspect the parameters and person object, then step through the DOM update. The original example assigned fname to lastName; the final version uses lname. The person example uses placeholder details.
Check DOM listing, paragraph insertion, cell changes, mouseover events and register/remove buttons.
The flatMap exercise is interpreted as flattening the pairs produced by map. The array is reset before the functional exercises to match the stated example.
